## 📖 Sobre o projeto

O **Museu Virtual da História da Computação** é [uma aplicação web / um site] que apresenta
marcos, personagens e invenções que moldaram a computação. O objetivo é [educar, preservar
a memória tecnológica e facilitar o acesso a esse conteúdo para estudantes e curiosos].

## ✨ Funcionalidades

- 🕰️ Linha do tempo interativa da história da computação
- 🖼️ Galerias temáticas (ex.: pré-história da computação, gerações de computadores, internet)
- 📱 Layout responsivo
